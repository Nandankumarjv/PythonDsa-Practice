# 125. Valid Palindrome

## Problem
Determine whether a string is a palindrome after removing non-alphanumeric characters and ignoring letter case.

## Approach
Use two pointers from both ends while skipping invalid characters.

## Algorithm
1. Initialize left and right pointers.
2. Skip non-alphanumeric characters.
3. Compare lowercase characters.
4. Continue until the pointers meet.

## Time Complexity
O(n)

## Space Complexity
O(1)

## Concepts
- Strings
- Two Pointers
